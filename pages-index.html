Markdown PR Review

This is not a website — it is a VS Code extension served as a folder, so vscode.dev can install it without the Marketplace.

In vscode.dev, run Developer: Install Extension From Location... and enter:

https://gndwgtgo.github.io/markdown-pr-review/

Then open a repo at vscode.dev/github/<owner>/<repo> and use Markdown PR Review: Open Review Panel.
